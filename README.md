# Shivam Pandey portfolio

A responsive React portfolio built with Vite.

## Run locally

```sh
npm install
npm run dev
```

For a production build, run `npm run build` and deploy the generated `dist/` directory to any static host. No backend is required for this version; contact actions use email and phone links.

## Personalize before publishing

- Add your actual LinkedIn and GitHub profile URLs if you want those links shown.
- Replace the resume PDF in `public/` when you update it.
- Review project descriptions and metrics for any client or employer confidentiality requirements.
